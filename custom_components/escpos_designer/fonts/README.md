# Bundled fonts

The designer draws every label itself, so the fonts it offers ship with it. All of them allow redistribution; the license texts are in [`licenses/`](licenses/).

| File | Font | License |
|------|------|---------|
| `DejaVuSans.ttf`, `DejaVuSansMono.ttf`, `DejaVuSerif.ttf` | DejaVu | Bitstream Vera / public domain |
| `PlayfairDisplay-SemiBold.ttf` | Playfair Display | SIL OFL 1.1 |
| `CourierPrime-Regular.ttf` | Courier Prime | SIL OFL 1.1 |
| `SpecialElite-Regular.ttf` | Special Elite | Apache 2.0 |
| `BebasNeue-Regular.ttf` | Bebas Neue | SIL OFL 1.1 |
| `Caveat-SemiBold.ttf` | Caveat | SIL OFL 1.1 |
| `Pacifico-Regular.ttf` | Pacifico | SIL OFL 1.1 |
| `NotoEmoji-Regular.ttf` | Noto Emoji (monochrome) | SIL OFL 1.1 |

Variable fonts (Caveat, Playfair Display, Noto Emoji) were instantiated at a fixed weight to keep the files small.
